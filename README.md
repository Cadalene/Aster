# Aster

Aster 是一个面向等保测评现场的离线取证工具，用于在手机上按项目、设备和取证项整理照片与文字记录，减少现场反复复制便签模板的操作。

## 主要功能

- 创建项目，并在项目下管理设备；创建和改名不允许与已有项目重名；
- 使用设备类型模板快速生成固定取证项；
- 支持新增、修改、删除、复制和拖动排序设备类型模板；
- 支持“项目整体情况”固定模板，用于记录系统整体接入情况；
- 通过手机系统相机拍摄照片，保留原始照片质量；
- 支持从相册导入照片、查看大图、删除照片和保存到相册；
- 同一取证项支持多张照片和可选文字备注；
- 取证项支持“已记录·符合”“已记录·不符合”“不适用”和“未记录”等状态；
- 支持导出关键设备截图 Word 文档；
- 可选上传 DOCX Word 模板；未设置模板时继续使用原有生成格式，设置后保留模板内容并在文末追加关键截图；
- 设备类型模板的每个取证项可维护可选的多行“核查方式”，并复制到新建项目和设备的取证项记录中；
- 支持导出项目浏览包，在 PC 浏览器中离线查看设备取证记录；
- 浏览包保留 HEIC 原图，同时为浏览器生成 JPEG 浏览副本；原有缩略图照常生成；
- 支持按设备类型筛选，并在同一取证项下使用键盘切换多张图片；
- PC 图片查看支持鼠标滚轮缩放、按住鼠标拖动，浏览器标签显示项目名称；
- 项目浏览包中的 `originals` 按设备类型和设备名称整理原始照片；
- 支持设备类型模板 JSON 导入、导出；
- 支持将所有项目的浏览包、Word 和模板串行导出为一个资料备份包；原图保留在各浏览包的 `originals` 内，不再额外重复保存；
- 备份前按所有项目原图总量的 1.2 倍估算备份文件，建议手机空闲空间按预计文件大小的 2.1 倍计算；生成和保存期间继续检查空间；
- 每台设备可单独关闭“需要取证”提醒；仅影响缺关键截图提示，不影响取证项和完成进度；
- 导出带日期，同名文件自动加序号，写入并回读校验后才提示完成；
- 支持离线使用，数据默认保存在手机本地；
- 支持“珊瑚红”和“纸张蓝”两种主题色，首次安装默认使用纸张蓝。

## 使用方式

1. 安装 [`release/Aster-v1.9.0-word-template-check-method-heic-release.apk`](release/Aster-v1.9.0-word-template-check-method-heic-release.apk)，升级时直接覆盖安装，不要先卸载。
2. 在 App 中创建项目，然后添加设备并选择对应的设备类型模板。
3. 进入取证项拍照或填写备注，记录会在操作后即时保存。
4. 在项目页面导出 Word 或项目浏览包（其中的 `originals` 保存原图）；在设置中导出模板或备份当前数据。
5. 项目浏览包可以直接在 PC 浏览器中打开其中的 `index.html`。

## 设备类型模板编辑器

`tools/等保取证设备类型模板编辑器.html` 是一个可直接在浏览器中打开的离线模板编辑工具。它可以读取和编辑设备类型模板 JSON，并导出可在 App 中导入的 JSON 文件。

示例模板文件：[`tools/等保取证_设备类型模板_20260904.json`](tools/等保取证_设备类型模板_20260904.json)

## 数据与兼容性说明

- App 不要求登录，主要面向个人或小范围离线使用；
- 项目、设备、模板、照片和备注默认保存在本机；
- 安装新版本前，建议先通过 App 导出项目浏览包或资料备份包，保留原始照片和项目数据；
- 正式版本使用固定应用包名和签名，后续版本会通过提高版本号覆盖升级；
- 请妥善保管导出的原始照片和项目浏览包，它们是现场取证资料的重要备份。
- 默认导出位置下自动创建分类子目录；选择其他位置时选一个文件夹，App 自动创建新文件，不覆盖之前的导出。
- 资料备份包仅包含各项目的浏览包、Word 及模板 JSON；浏览包内部保存完整原图。该备份不是数据库镜像，目前不支持项目一键还原。
- 备份预计文件按所有项目原图总量的 1.2 倍估算；建议手机空闲空间按预计文件大小的 2.1 倍预留。此为简化估算，实际生成过程仍会持续检查可用空间。
- 备份空间确认弹窗显示估算大小、建议手机空闲空间及当前可用空间。空间不足时不能开始，可清理空间后重新检查；正式开始和最终复制前会再次检查，写入期间至少每约 1 MiB 或 1 秒检查一次。
- Android 无法保证读取所有云盘和第三方文档提供器的剩余容量。无法检测保存位置容量时会明确提示，并保守计入本机目标副本；不能因此保证远端空间充足。
- 导出任务不能保证在系统强制终止 App 或断电后继续；中断的导出文件不可视为有效备份，完成提示出现后再检查并留存。源项目和原图不会因导出失败而删除。
