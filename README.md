# Aster

Aster 是一个面向等保测评现场的离线取证工具，用于在手机上按项目、设备和取证项整理照片与文字记录，减少现场反复复制便签模板的操作。

## 主要功能

- 创建项目，并在项目下管理设备；
- 使用设备类型模板快速生成固定取证项；
- 支持新增、修改、删除、复制和拖动排序设备类型模板；
- 支持“项目整体情况”固定模板，用于记录系统整体接入情况；
- 通过手机系统相机拍摄照片，保留原始照片质量；
- 支持从相册导入照片、查看大图、删除照片和保存到相册；
- 同一取证项支持多张照片和可选文字备注；
- 取证项支持“已记录·符合”“已记录·不符合”“不适用”和“未记录”等状态；
- 支持导出关键设备截图 Word 文档；
- 支持导出项目浏览包，在 PC 浏览器中离线查看设备取证记录；
- 支持按设备类型筛选，并在同一取证项下使用键盘切换多张图片；
- 支持导出原始照片，按设备类型和设备名称整理；
- 支持设备类型模板 JSON 导入、导出；
- 支持离线使用，数据默认保存在手机本地；
- 支持“珊瑚红”和“纸张蓝”两种主题色，首次安装默认使用纸张蓝。

## 使用方式

1. 安装 [`release/Aster-v1.4.3-paper-blue-default-release.apk`](release/Aster-v1.4.3-paper-blue-default-release.apk)。
2. 在 App 中创建项目，然后添加设备并选择对应的设备类型模板。
3. 进入取证项拍照或填写备注，记录会在操作后即时保存。
4. 在项目页面导出 Word、项目浏览包或原始照片。
5. 项目浏览包可以直接在 PC 浏览器中打开其中的 `index.html`。

## 设备类型模板编辑器

`tools/等保取证设备类型模板编辑器.html` 是一个可直接在浏览器中打开的离线模板编辑工具。它可以读取和编辑设备类型模板 JSON，并导出可在 App 中导入的 JSON 文件。

示例模板文件：[`tools/等保取证_设备类型模板_20260904.json`](tools/等保取证_设备类型模板_20260904.json)

## 数据与兼容性说明

- App 不要求登录，主要面向个人或小范围离线使用；
- 项目、设备、模板、照片和备注默认保存在本机；
- 安装新版本前，建议先通过 App 导出原始照片和项目数据；
- 正式版本使用固定应用包名和签名，后续版本会通过提高版本号覆盖升级；
- 请妥善保管导出的原始照片和项目浏览包，它们是现场取证资料的重要备份。
